# AI Software Engineering Roadmap

**12 semanas · 60 sessões · 180 horas · 9 módulos**

Trilha independente para pessoas que já programam e querem projetar, construir, avaliar e manter software com IA. A aprendizagem é **incremental, iterativa e baseada em evidências**.

Comece pelo [Guia rápido](quickstart.md), continue com o [Cronograma](roadmap.md) e faça cada sessão na ordem. Cada dia reserva 3 horas, define uma prática, um entregável e um critério de aceite.

> Este curso é executável em **modo mock**, sem chaves pagas. Para experimentos com modelos reais, configure um serviço local compatível ou um provedor de sua escolha.

## O que será desenvolvido

Um **AI Engineering Assistant**: API → RAG → tools/MCP → investigação assistida por agente → avaliações → documentação e demonstração. O projeto é evolutivo; os exercícios não devem ser descartados ao final de cada semana.

## Regras de estudo

1. Faça a prática antes de consultar uma solução.
2. Versione os entregáveis com código, teste e registro breve de decisões.
3. Verifique cada critério de aceite; anote lacunas com honestidade.
4. Conclua a retrospectiva semanal antes de seguir.
5. Prefira conceitos transferíveis a depender de um único framework.
