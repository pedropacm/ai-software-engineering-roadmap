# Módulo 05 — Function calling e MCP

**Carga:** 15 horas · **Semanas:** 6

## Objetivo

Disponibilizar ferramentas sob contratos explícitos e limites de segurança.

## Escopo

- Json schema de tools
- Ciclo de execução
- Mcp clients/servers
- Tools/resources/prompts
- Autenticação
- Controle de acesso

## Ideia central

Tool calling não significa deixar o modelo executar comandos arbitrários. O modelo seleciona uma função e propõe parâmetros; o código valida argumentos e impõe autorização. MCP padroniza a descoberta/uso de ferramentas, não substitui os controles de segurança. Comece com funções apenas de leitura, dados simulados e logs sem conteúdo sensível.

## Projeto de conclusão

**Entrega:** Engineering MCP Server somente leitura com 3 tools.

**Critério de conclusão:** Demonstrar chamada validada, tratamento de erro e ausência de permissões destrutivas.

### Comprovação mínima

1. Código, documentos ou artefato acessível no seu fork.
2. Evidência de execução (comandos e resultado) sem segredos.
3. Testes ou cenários de avaliação que outra pessoa consegue repetir.
4. Registro curto de pelo menos uma decisão técnica e uma limitação.
