# Módulo 03 — Desenvolvimento assistido por IA

**Carga:** 15 horas · **Semanas:** 3

## Objetivo

Adotar workflow AI-first sem abdicar de revisão e testes humanos.

## Escopo

- Plano antes do código
- Agents de codificação
- Regras de projeto
- Tdd
- Review
- Segurança de sugestões
- Refatoração

## Ideia central

Um coding agent acelera a produção de diffs, mas aumenta a necessidade de especificações e revisões. Construa em ciclos pequenos: requisito observável, plano, alteração mínima, teste automatizado e revisão humana. Documente os prompts que influenciaram decisões importantes e não exponha tokens, segredos ou dados privados ao contexto do agente.

## Projeto de conclusão

**Entrega:** Feature implementada por ciclos de especificação, geração, revisão e testes.

**Critério de conclusão:** PR documenta prompts, decisões, diffs, testes, bugs de código gerado e ganhos reais.

### Comprovação mínima

1. Código, documentos ou artefato acessível no seu fork.
2. Evidência de execução (comandos e resultado) sem segredos.
3. Testes ou cenários de avaliação que outra pessoa consegue repetir.
4. Registro curto de pelo menos uma decisão técnica e uma limitação.
