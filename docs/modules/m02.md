# Módulo 02 — APIs de LLM e engenharia de contexto

**Carga:** 15 horas · **Semanas:** 2

## Objetivo

Encapsular chamadas probabilísticas em uma API com contratos e resiliência.

## Escopo

- Papéis de mensagem
- Prompts
- Few-shot
- Structured outputs
- Schemas
- Streaming
- Retries
- Timeouts
- Custo
- Fallback

## Ideia central

A aplicação mantém as responsabilidades de autorização, validação, limites, erros e controle de orçamento. O modelo produz propostas; quem decide executar ações é seu código. Prefira contratos claros e verificação de esquema em vez de confiar em frases como “responda apenas JSON”. Retry deve ser restrito a falhas transitórias, com limites; não repita cegamente operações de escrita.

## Projeto de conclusão

**Entrega:** AI Gateway local com provider abstrato, validações e testes.

**Critério de conclusão:** Gateway oferece endpoint /chat, testes automatizados e tratamento de respostas inválidas.

### Comprovação mínima

1. Código, documentos ou artefato acessível no seu fork.
2. Evidência de execução (comandos e resultado) sem segredos.
3. Testes ou cenários de avaliação que outra pessoa consegue repetir.
4. Registro curto de pelo menos uma decisão técnica e uma limitação.
